# FitLog

> A focused workout library for choosing today's training, saving future sessions, and tracking progress.

FitLog helps users turn a large workout library into a simple daily plan. Browse exercises, inspect the details, save favorites for later, and mark completed workouts as you build a consistent routine.

## Technologies Used

- **Next.js 16** - App Router and dynamic workout pages
- **React 19** - Interactive client components and shared state
- **Tailwind CSS 4** - Responsive styling and layout
- **JavaScript** - Application logic and UI behavior
- **REST API** - Workout data source
- **LocalStorage** - Persistent plan, saved, and completed workout data

## Key Features

1. **Workout library** - Browse a responsive collection of exercises with useful workout metadata.
2. **Workout details** - Open a dynamic details page with equipment, difficulty, sets, reps, stats, muscle groups, and instructions.
3. **Today's plan** - Add up to five workouts to a daily plan and mark them as completed.
4. **Save for later** - Keep workouts in a separate saved list for future sessions.
5. **Search, sort, and manage** - Find workouts by name or muscle group, sort by duration, calories, or rating, and remove items from either list.
