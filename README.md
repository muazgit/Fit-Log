# FitLog

FitLog is a responsive workout library and workout planning website. Users can browse workouts, view detailed workout information, add exercises to today's plan, save workouts for later, search and sort workouts, and manage their workout plan.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- JavaScript
- REST API
- LocalStorage

## Features

- Browse workout library with workout details
- View dynamic workout details pages
- Add workouts to today's plan
- Save workouts for later
- Search workouts by name or tag
- Sort workouts by duration, calories, or rating
- Mark workouts as done
- Remove workouts from plan or saved list
- Persistent plan and saved data using LocalStorage
- Responsive design for mobile, tablet, and desktop
